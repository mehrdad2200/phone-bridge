## اجرای برنامه

| نشانه | علت ← راه‌حل |
|---|---|
| `Python was not found; run without arguments to install from the Microsoft Store` | میانبر Store ویندوز جلوی پایتون را گرفته. از **`py phone_bridge.py`** استفاده کن، یا پایتون را با تیک *Add python.exe to PATH* دوباره نصب کن، یا در تنظیمات *App execution aliases* مربوط به `python.exe` را خاموش کن. |
| `ModuleNotFoundError: No module named 'PyQt6'` / `'pynput'` | `py -m pip install -r requirements.txt` (با همان `py`/`python` که برنامه را با آن اجرا می‌کنی). |
| دستور `pip install …` را **داخل** پیام پایتون (`>>>`) نوشته‌ای | اول `exit()` بزن، بعد دستور را در ترمینال معمولی اجرا کن. |
| اجرای `phone_bridge(1).py` در PowerShell «not recognized» می‌دهد | اسم فایل را بدون پرانتز کن و `py phone_bridge.py` را اجرا کن. |
| `qt.qpa.plugin: Could not load the Qt platform plugin "xcb"` (لینوکس) | `sudo apt install libxcb-cursor0 libxkbcommon-x11-0 libegl1`. |
| پنجره خالی باز می‌شود / روی پایتونِ خیلی جدید کرش می‌کند | پایتون ۳٫۱۲ یا ۳٫۱۳ را امتحان کن؛ نسخه‌ی PyQt6 برای پایتون‌های تازه ممکن است دیر برسد. |
| بعد از دکمه‌ی زبان اتفاقی نمی‌افتد | برنامه خودش دوباره اجرا می‌شود؛ اگر نشد دستی اجرایش کن — زبان جدید همان‌موقع ذخیره شده است. |

## adb و اتصال

| نشانه | علت ← راه‌حل |
|---|---|
| `[WinError 2] The system cannot find the file specified` یا *adb پیدا نشد* | adb نصب نیست. **تب اتصال ← دانلود خودکار adb** (یا *انتخاب adb.exe*). |
| دانلود شکست می‌خورد | شاید شبکه‌ات `dl.google.com` را بسته. از **باز کردن صفحه‌ی دانلود در مرورگر** استفاده کن، zip را جایی باز کن و **انتخاب adb.exe** را بزن. |
| لیست دستگاه `unauthorized` نشان می‌دهد | گوشی را باز کن و **Allow USB debugging?** را تأیید کن (*Always allow*). نشد؟ *Developer options ← Revoke USB debugging authorizations* و دوباره وصل کن. |
| دستگاه `offline` است | کابل را دوباره بزن؛ USB debugging را خاموش/روشن کن؛ یا `adb kill-server` بزن و تازه‌سازی را بزن. |
| `more than one device/emulator` | قبل از *اتصال به دستگاه انتخاب‌شده* مورد درست را از لیست انتخاب کن؛ یا بقیه را جدا کن. |
| وصل می‌شود ولی هر چند دقیقه قطع می‌شود (Wi-Fi) | صرفه‌جویی باتری گوشی وای‌فای را می‌کُشد: وای‌فای را «همیشه روشن» بگذار، از بهینه‌سازی باتری مستثنایش کن، و *اتصال خودکار مجدد* را تیک‌دار نگه دار. |
| با کابل، `adb devices` خالی است | از کابل **داده** استفاده کن (نه فقط شارژ)، حالت USB را *File transfer* بگذار، درایور USB سازنده را در ویندوز نصب کن (Google USB driver یا درایور خود برند). |

## تصویر

| نشانه | علت ← راه‌حل |
|---|---|
| پنجره‌ی سیاه با پیام قرمز زیرش | پیام علت را می‌گوید: `unauthorized`، `offline`، «screencap تصویر نداد»، … اول آن را درست کن. |
| «تصویر گوشی کاملاً سیاه است» | صفحه‌ی گوشی **خاموش/قفل** است (*بیدار کردن و باز کردن قفل* را بزن)، یا برنامه‌ی جلوی صفحه ضبط تصویر را بسته (برنامه‌های بانکی، بعضی برنامه‌های ویدیو، صفحه‌های *secure*). این محدودیت اندروید است و Phone Bridge نمی‌تواند دورش بزند. |
| تصویر کند به‌روز می‌شود (۱ تا ۳ FPS) | بر پایه‌ی اسکرین‌شات است. **نمایش زنده ← سریع (۰٫۲۵ ثانیه)** را انتخاب کن، **کابل USB** را به Wi-Fi ضعیف ترجیح بده، logcat تب توسعه را ببند، و بدان بعضی گوشی‌ها برای هر `screencap` ۳۰۰ تا ۶۰۰ میلی‌ثانیه وقت می‌گیرند. برای ویدیوی روان از scrcpy استفاده کن. |
| تصویر خوابیده است | گوشی را بچرخان یا دکمه‌ی **چرخش** نوار ابزار را بزن. |
| تصویر تار است | نمایشگر به اندازه‌ی پنجره کوچک/بزرگ می‌شود — پنجره را بزرگ‌تر کن. |

## لمس و تایپ کار نمی‌کند

صفحه دیده می‌شود ولی کلیک اثری ندارد:

1. **شیائومی / ردمی / پوکو:** *Developer options ← **USB debugging (Security settings)*** باید روشن باشد (ورود به حساب Mi می‌خواهد). در بعضی نسخه‌های Oppo/Realme/Vivo هم گزینه‌ای شبیه *«Disable permission monitoring»* / *«USB debugging (security)»* هست.
2. دستی تست کن: **تب توسعه ← ترمینال adb** را باز کن و `input tap 540 1200` را بزن. اگر آن هم لمس نکرد، مشکل از تنظیمات گوشی است نه برنامه.
3. شاید گوشی یک دیالوگ امنیتی سیستم (درخواست مجوز، صفحه‌ی قفل) نشان می‌دهد که ورودی تزریقی را نادیده می‌گیرد — یک‌بار روی خود گوشی لمسش کن.

تایپ: اگر فیلد متن روی گوشی فعال باشد ASCII کار می‌کند. برای فارسی [پایین‌تر](#تایپ-فارسی-داخل-گوشی) را ببین.

## جفت‌سازی QR / بی‌سیم

| نشانه | علت ← راه‌حل |
|---|---|
| دوربین معمولی گوشی متن عجیب نشان می‌دهد یا هیچ | از **Developer options ← Wireless debugging ← Pair device with QR code** اسکن کن (اسکنر خودش باز می‌شود). |
| «زمان تمام شد؛ گوشی QR را اسکن نکرد» | کامپیوتر سرویس جفت‌سازی گوشی را ندید. چک کن: گوشی و PC روی **یک** وای‌فای باشند؛ شبکه‌ی *مهمان* / *AP isolation* نباشد؛ روی هیچ‌کدام **VPN** نباشد؛ Wireless debugging روشن باشد؛ فایروال ویندوز `adb.exe` را روی شبکه‌ی خصوصی اجازه دهد. بعد دوباره امتحان کن یا از **کد جفت‌سازی** استفاده کن. |
| «این نسخه‌ی adb از mDNS پشتیبانی نمی‌کند» | به آخرین Platform-Tools به‌روزرسانی کن (دکمه‌ی دانلود برنامه). |
| «جفت‌سازی ناموفق بود» | رمز یک‌بارمصرف منقضی شده — دوباره **ساخت QR و شروع** را بزن. |
| «جفت شد؛ ولی پورت اتصال پیدا نشد» | جفت‌سازی درست بوده؛ **IP:پورت** صفحه‌ی اصلی *Wireless debugging* را در کادر بی‌سیم بنویس و **اتصال** را بزن. |
| یک روز کار می‌کند بعد نه | پورت بی‌سیم هر بار که Wireless debugging خاموش/روشن شود یا گوشی ری‌استارت شود عوض می‌شود — دوباره جفت/وصل کن. |
| گوشی هات‌اسپات کامپیوتر است (یا برعکس) | کار می‌کند ولی ممکن است mDNS فیلتر شود؛ کد جفت‌سازی بهتر است. |

## صفحه‌ی ریموت روی گوشی

| نشانه | علت ← راه‌حل |
|---|---|
| آدرس روی گوشی باز نمی‌شود | همان وای‌فای؟ از **http://** (نه https) استفاده کن. در فایروال ویندوز Python را برای شبکه‌ی **Private** اجازه بده (Start ← *Allow an app through Windows Firewall*). روتر «client isolation» دارد؟ هات‌اسپات گوشی را امتحان کن. |
| `403 forbidden` | توکن لینک کهنه است. توکن جدید تصادفی **هر بار که برنامه اجرا می‌شود** (و با *توکن جدید*) ساخته می‌شود، پس بوکمارک‌های قدیمی از کار می‌افتند. آدرس فعلی را از برنامه کپی کن یا QR را دوباره اسکن کن. |
| در برنامه «پورت اشغال است» | برنامه‌ی دیگری از ۸۷۶۵ استفاده می‌کند. **پورت** را عوض کن و سرور را خاموش/روشن کن. |
| تایپ می‌شود ولی مکان‌نما می‌پرد / متن تکراری می‌شود | بعد از تمام شدن هر جمله **پاک کردن کادر** را بزن؛ صفحه نسخه‌ای از محتوای کادر نگه می‌دارد تا تفاوت‌ها را حساب کند. |
| تاچ‌پد زیادی تند/کند است | در نسخه‌ی ۱٫۰ سرعت روی یک پیش‌فرض راحت ثابت است؛ نقشه‌ی راه را ببین. اسکرول دوانگشتی *طبیعی* است (محتوا دنبال انگشت می‌آید). |
| *صفحه‌ی PC* می‌گوید خاموش است | در برنامه **نمایش و کنترل صفحه‌ی کامپیوتر از گوشی** را تیک بزن. |
| دکمه‌های *سیستم* کاری نمی‌کنند | در برنامه **دستورهای سیستمی** را تیک بزن؛ فقط ویندوز پشتیبانی می‌شود. |
| فارسی تایپ‌شده از گوشی روی PC مربع می‌شود | برنامه‌ی مقصد روی PC فونت/کیبورد فارسی ندارد — مشکل Phone Bridge نیست. |
| فونت صفحه Tahoma است نه وزیرمتن | هنگام بارگذاری صفحه فونت‌ها روی PC نبوده‌اند. چک کن پوشه‌ی `fonts` کنار برنامه `Vazirmatn-*.ttf` دارد و صفحه را دوباره بارگذاری کن. |

## تایپ فارسی داخل گوشی

دو چیز اینجا با هم قاطی می‌شود:

- **گوشی ← PC (تایپ روی کامپیوتر با کیبورد گوشی):** فارسی بی‌دردسر کار می‌کند — از صفحه‌ی *تایپ* ریموت استفاده کن.
- **PC ← گوشی (تایپ در یک فیلد روی گوشی از کامپیوتر):** `adb` فقط کلیدهای ASCII را تزریق می‌کند، **نه** حروف فارسی. برای فارسی/یونیکد به یک کیبورد کمکی روی گوشی نیاز داری:

1. APK متن‌باز **[ADBKeyBoard](https://github.com/senzhk/ADBKeyBoard)** را روی گوشی نصب کن (می‌توانی فایل `.apk` را روی پنجره‌ی Phone Bridge بکشی و رها کنی تا نصب شود).
2. آن را به‌عنوان روش ورودی فعال و انتخاب کن (تنظیمات گوشی ← *Languages & input ← On-screen keyboard*؛ یا با دستورهای `ime enable` / `ime set` از README خود ADBKeyBoard که می‌توانی در **ترمینال adb** اجرا کنی).
3. در Phone Bridge: *کنترل ← ورودی* ← **فارسی/یونیکد با ADBKeyboard** را تیک بزن، در کادر بنویس و **ارسال** را بزن. برنامه متن را Base64 و به‌صورت broadcast با نام `ADB_INPUT_B64` می‌فرستد و آن کیبورد در فیلد فعال تایپش می‌کند.
4. بعدش کیبورد معمولی‌ات را برگردان.

تایپ مستقیم روی *نمایشگر* گوشی با کیبورد PC هم برای نویسه‌های غیر ASCII از همین مسیر می‌رود (و اگر گزینه خاموش باشد راهنمایی نشان می‌دهد).

## ضبط، دوربین، تنظیمات سریع

| نشانه | علت ← راه‌حل |
|---|---|
| ضبط «ناموفق» می‌شود / فایل خالی است | `screenrecord` روی بعضی گوشی‌ها نیست (و هنگام پخش محتوای DRM/secure بسته است). سقف هر ضبط ۳ دقیقه است. فضای خالی گوشی را چک کن. |
| دکمه‌ی دوربین عکس نگرفت | همه‌ی برنامه‌های دوربین به رویداد کلید شاتر واکنش نشان نمی‌دهند. روی نمایشگر شاتر را بزن و بعد **آخرین عکس گوشی را بیاور** را بزن. |
| *داده‌ی موبایل / Wi-Fi / مزاحم نشوید / حالت تاریک* کاری نمی‌کنند | این‌ها دستورهای `svc`/`cmd` هستند که بعضی نسخه‌های اندروید یا ROMهای سازنده محدودشان کرده‌اند. پیام نوار وضعیت را ببین؛ همان دستور را در *ترمینال adb* امتحان کن و خروجی را در Issue بنویس. |
| *پاک کردن کش همه‌ی برنامه‌ها* اثری ندارد | اندروید ۸+ این کار را روی بسیاری از گوشی‌ها برای کاربر shell محدود کرده؛ برنامه‌ها را یکی‌یکی از تب **برنامه‌ها** پاک کن. |
| نوار *روشنایی* نادیده گرفته می‌شود | بعضی سازنده‌ها آن را با روشنایی تطبیقی لغو می‌کنند؛ روشنایی تطبیقی را در گوشی خاموش کن. |

## فونت و زبان

- برنامه فارسی را با **وزیرمتن** نشان می‌دهد. اگر فونت دیگری دیدی، پوشه‌ی `fonts` را چک کن ([پوشه‌ی داده](getting-started.md#گزینههای-خط-فرمان-و-پوشهی-داده)). پاکش کن تا دوباره دانلود شود.
- شروع با یک زبان خاص: `python phone_bridge.py --lang en` (یا `fa`).
- چیدمان راست‌به‌چپ برای فارسی خودکار است؛ اگر برچسبی با ترکیب فارسی/انگلیسی عجیب بود، الگوریتم bidi یونیکد است — لطفاً با اسکرین‌شات گزارش کن.

## پرسش‌های رایج

**باید روی گوشی برنامه نصب کنم؟**
نه. همه‌چیز از راه `adb` (PC←گوشی) و مرورگر گوشی (گوشی←PC) است. فقط *تایپ فارسی داخل گوشی* اختیاراً به کیبورد ADBKeyBoard نیاز دارد.

**با USB و Wi-Fi هر دو کار می‌کند؟**
هر دو. USB سریع‌تر و پایدارتر است؛ Wi-Fi راحت‌تر.

**اینترنت لازم دارد؟**
نه. اینترنت فقط برای دانلودهای اختیاری (فونت، Platform-Tools) است. صفحه‌ی گوشی و بقیه‌چیز روی شبکه‌ی محلی بدون اینترنت کار می‌کند. (تست *Ping* لازم دارد گوشی به مقصدش برسد.)

**صفحه‌ی گوشی روی آیفون کار می‌کند؟**
یک صفحه‌ی وب معمولی است و باید در Safari کار کند، ولی برای مرورگرهای اندروید/Chrome ساخته و تست شده؛ لرزش (`navigator.vibrate`) در iOS وجود ندارد.

**امن است؟**
[امنیت](security.md) را بخوان. خلاصه: توکن تصادفی، فقط شبکه‌ی محلی، قابلیت‌های پرخطر اختیاری، بدون تله‌متری.

**چند کامپیوتر یک گوشی را یا یک کامپیوتر چند گوشی را کنترل کند؟**
هر پنجره یک گوشی. می‌توانی دو پنجره با `PHONE_BRIDGE_HOME` و پورت‌های متفاوت اجرا کنی.

**چرا بر پایه‌ی اسکرین‌شات است نه ویدیو؟**
سادگی و نیاز نداشتن به نصب روی گوشی. ویدیو یک پردازه‌ی کمکی روی گوشی می‌خواهد (کاری که scrcpy می‌کند).

**تنظیماتم کجاست؟**
`phone_bridge_config.json` در پوشه‌ی داده — [شروع سریع](getting-started.md#گزینههای-خط-فرمان-و-پوشهی-داده).

**چطور به‌روزرسانی کنم؟**
`git pull` (یا ZIP جدید را بگیر) — تنظیمات می‌مانند چون در پوشه‌ی داده‌اند / در git نادیده گرفته می‌شوند.

**چطور حذفش کنم؟**
پوشه را پاک کن (و `~/.phone-bridge` اگر با pip نصب کردی). در گوشی: *Developer options ← Revoke USB debugging authorizations* و Wireless debugging را خاموش کن.

## گزارش خطا

با فرم Issue باز کن و این‌ها را بگذار:

1. `python phone_bridge.py --version`، سیستم‌عامل و نسخه‌ی پایتون.
2. مدل گوشی + نسخه‌ی اندروید (+ رابط سازنده: MIUI، One UI، …).
3. روش اتصال (USB / QR / کد).
4. کادر **گزارش adb** از تب اتصال و هر پیام قرمز زیر نمایشگر.
5. اگر ظاهری است، یک اسکرین‌شات.

هرگز کد جفت‌سازی، تصویر QR یا آدرس صفحه‌ی ریموت (که توکن دسترسی‌ات را دارد) را منتشر نکن.
