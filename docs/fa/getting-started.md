## ۱. نصب

### پیش‌نیازها

| | |
|---|---|
| **پایتون** | نسخه‌ی ۳٫۱۰ یا بالاتر (تست‌شده روی ۳٫۱۰، ۳٫۱۲ و ۳٫۱۳). در ویندوز از [python.org](https://www.python.org/downloads/) نصب کن و تیک **Add python.exe to PATH** را بزن. |
| **کامپیوتر** | ویندوز ۱۰/۱۱ (اصلی)، لینوکس (کار می‌کند؛ دستورهای خاموشی از صفحه‌ی گوشی فقط ویندوز). macOS تست نشده. |
| **گوشی** | اندروید ۵ به بالا برای USB؛ **اندروید ۱۱ به بالا** برای جفت‌سازی بی‌سیم و QR. |
| **شبکه** | برای Wi-Fi، گوشی و کامپیوتر باید روی **یک** وای‌فای/شبکه باشند (نه شبکه‌ی مهمان با «client isolation»). |
| **adb** | برنامه می‌تواند خودش دانلودش کند (Platform-Tools گوگل، حدود ۷ مگابایت) — یا از adb خودت استفاده کن. |

### ویندوز

1. پایتون ۳٫۱۰+ را نصب کن (با تیک *Add to PATH*).
2. این مخزن را بگیر (`Code ← Download ZIP` یا `git clone`) و از حالت فشرده خارج کن.
3. روی **`scripts\run.bat`** دوبار کلیک کن. بار اول دو کتابخانه (`PyQt6` و `pynput`) نصب می‌شود و بعد برنامه باز می‌شود.

روش دستی (PowerShell یا cmd):

```bat
cd path\to\phone-bridge
py -m pip install -r requirements.txt
py phone_bridge.py
```

> اگر `python` پیام *"Python was not found"* داد (میانبر Microsoft Store)، به‌جایش از **`py`** استفاده کن، یا در تنظیمات ویندوز *App execution aliases* مربوط به python را خاموش کن.

### لینوکس / مک

```bash
./scripts/run.sh                       # بار اول .venv می‌سازد
# یا
pip install -r requirements.txt && python3 phone_bridge.py
```

در لینوکس ممکن است به کتابخانه‌های Qt نیاز باشد (`libxcb-cursor0`، `libxkbcommon-x11-0`، `libegl1`). در macOS برای `pynput` باید در *System Settings ← Privacy & Security ← Accessibility* به ترمینال/برنامه اجازه بدهی.

### به‌صورت بسته (pip)

```bash
pip install .          # از داخل پوشه‌ی مخزن
phone-bridge           # برنامه را اجرا می‌کند؛ تنظیمات در ~/.phone-bridge
```

### اولین اجرا

بار اول برنامه فونت **وزیرمتن** (۳ فایل کوچک) را در پوشه‌ی `fonts` کنار برنامه دانلود می‌کند. اگر آفلاین باشی از فونت سیستم استفاده می‌کند و دفعه‌ی بعد دوباره تلاش می‌کند. می‌توانی خودت هم `Vazirmatn-Regular.ttf` و `-Medium.ttf` و `-Bold.ttf` را داخل آن پوشه بگذاری.

## ۲. آماده‌سازی گوشی

برای هر گوشی فقط یک‌بار.

1. **فعال‌کردن Developer options** — *تنظیمات ← درباره‌ی گوشی* ← هفت بار روی **Build number** بزن (در بعضی گوشی‌ها زیر *Software information* است).
2. **روشن‌کردن USB debugging** — *تنظیمات ← سیستم ← Developer options ← USB debugging*.
3. **فقط شیائومی / ردمی / پوکو (MIUI/HyperOS):** گزینه‌ی **«USB debugging (Security settings)»** و در صورت وجود **«Install via USB»** را هم روشن کن. بدون آن، لمس و تایپ بی‌صدا نادیده گرفته می‌شود، با اینکه صفحه دیده می‌شود.
4. برای **وای‌فای بدون کابل (اندروید ۱۱+):** در Developer options گزینه‌ی **Wireless debugging** را روشن کن (ممکن است اجازه‌ی استفاده روی شبکه‌ی فعلی را بخواهد).
5. بار اول گوشی را **باز (unlock)** نگه دار — اندروید برای هر کامپیوتر جدید پیام *«Allow USB debugging?»* می‌دهد؛ *Always allow* را تیک بزن و تأیید کن.

## ۳. اتصال — یکی از روش‌ها را انتخاب کن

تب **اتصال** را باز کن.

### گام A — گرفتن adb (یک‌بار)

| دکمه | کار |
|---|---|
| **پیدا کردن خودکار** | در `PATH`، کنار برنامه، `ANDROID_HOME` و پوشه‌های رایج می‌گردد. |
| **انتخاب adb.exe** | خودت انتخاب کن (مثلاً از SDK اندروید استودیو). |
| **دانلود خودکار adb** | zip رسمی *Platform-Tools* گوگل را می‌گیرد و در `platform-tools/` کنار برنامه باز می‌کند. |
| **باز کردن صفحه‌ی دانلود در مرورگر** | اگر دانلود روی شبکه‌ات بسته است: zip را خودت بگیر، از حالت فشرده خارج کن و *انتخاب adb.exe* را بزن. |

وقتی adb آماده باشد، خط وضعیت ✅ و مسیر را نشان می‌دهد.

### روش ۱ — کابل USB (ساده‌ترین)

1. گوشی را وصل کن و پیام روی گوشی را تأیید کن.
2. دکمه‌ی تازه‌سازی کنار لیست دستگاه‌ها را بزن ← گوشی با وضعیت `device` ظاهر می‌شود.
3. **اتصال به دستگاه انتخاب‌شده** را بزن.

به‌محض رسیدن اولین تصویر، برنامه به تب **کنترل** می‌رود. اگر فقط یک دستگاه وصل باشد، موقع شروع برنامه خودکار وصل می‌شود.

*می‌خواهی بعدش کابل را بکشی؟* وقتی کابل هنوز وصل است **«با کابل USB وصل است؛ تبدیل به وای‌فای»** را بزن. برنامه IP گوشی را می‌خواند، `adb tcpip 5555` را اجرا می‌کند، بی‌سیم وصل می‌شود و می‌گوید کی می‌توانی کابل را جدا کنی.

### روش ۲ — کد QR (اندروید ۱۱+، بدون کابل)

1. در کامپیوتر: **ساخت QR و شروع**. یک QR ظاهر می‌شود و وضعیت می‌گوید *«منتظر اسکن QR توسط گوشی…»*.
2. در گوشی: *Developer options ← Wireless debugging ← **Pair device with QR code*** و QR روی صفحه‌ی کامپیوتر را اسکن کن.
   *از همین اسکنر استفاده کن — دوربین معمولی نمی‌تواند آن را بخواند.*
3. برنامه گوشی را روی شبکه پیدا می‌کند (mDNS)، جفت می‌کند و وصل می‌شود. وضعیت: *گوشی پیدا شد ← جفت شد ← ✅ وصل شد*. تب کنترل باز می‌شود.

اگر مشکلی پیش آمد، طرز کار: QR یک نام سرویس و رمز یک‌بارمصرف دارد (`WIFI:T:ADB;S:studio-xxxx;P:xxxxxxxx;;`). گوشی سرویس جفت‌سازی با همان نام را اعلام می‌کند؛ برنامه آن را با `adb mdns services` پیدا می‌کند، `adb pair <ip:port> <رمز>` را اجرا می‌کند، منتظر سرویس اتصال گوشی می‌ماند و `adb connect` می‌زند. اگر روتر mDNS را ببندد (وای‌فای مهمان، «AP isolation»، VPN) بعد از حدود ۲٫۵ دقیقه تمام می‌شود — از روش ۳ استفاده کن.

### روش ۳ — کد جفت‌سازی

1. در گوشی: *Wireless debugging ← **Pair device with pairing code***. **IP:پورت** و کد ۶ رقمی نمایش‌داده‌شده را یادداشت کن.
2. در برنامه، زیر *اتصال به گوشی*: IP:پورت را در **IP:پورت جفت‌سازی**، کد را در **کد ۶ رقمی** بنویس و **جفت‌سازی** را بزن.
3. در صفحه‌ی اصلی *Wireless debugging* یک **IP:پورت** (متفاوت!) دیگر هست؛ آن را در کادر بی‌سیم بنویس ← **اتصال**.

### روش ۴ — دستی

اگر گوشی از قبل روی یک پورت TCP گوش می‌دهد (مثلاً بعد از `adb tcpip 5555` با ابزار دیگر)، `IP:5555` را در کادر بی‌سیم بنویس و **اتصال** را بزن. آخرین آدرس به خاطر سپرده می‌شود.

## ۴. اولین نگاه

تب **کنترل**:

- **کنار نوار ابزار:** نمایش زنده‌ی گوشی. موس را رویش ببر — قرص پایین `x y #رنگ` پیکسل زیر نشانگر را نشان می‌دهد؛ قرص بالا-چپ FPS است.
- **نوار ابزار عمودی:** برگشت · خانه · برنامه‌های اخیر · روشن/خاموش · صدا ± · اسکرین‌شات · کپی تصویر · ضبط · چرخش · اعلان‌ها · باز کردن پوشه.
- **پنل کناری** (۳ صفحه): *کنترل* (حرکت‌ها، بیدار کردن و باز کردن قفل، روشنایی، کلیدهای رسانه، گزینه‌های نمایش)، *ورودی* (تایپ روی گوشی)، *ماکرو*.

امتحان کن: روی یک آیکون در نمایشگر کلیک کن (= لمس)، بکش (= swipe)، چرخ موس را بچرخان، با کلیک راست برگرد.
برای تایپ: یک‌بار روی نمایشگر کلیک کن و بعد با کیبورد کامپیوتر بنویس.

توضیح کامل همه‌چیز: **[راهنمای استفاده](usage.md)**.

## ۵. گوشی به‌عنوان ریموت کامپیوتر

1. تب **کیبورد و ریموت PC**. سرور خودکار روشن می‌شود و آدرسی مثل `http://192.168.1.9:8765/?t=Ab3dEf9Z` نشان می‌دهد.
2. در گوشی (روی همان وای‌فای) آن آدرس را در هر مرورگری باز کن — یا QR زیر آدرس را با دوربین اسکن کن.
3. صفحه پنج تب پایین دارد: **تایپ**، **تاچ‌پد**، **ارائه**، **رسانه**، **بیشتر** (میانبرها، صفحه‌ی PC، کلیپ‌بورد، سیستم).
4. ویندوز ممکن است اجازه‌ی عبور Python از فایروال را بپرسد — **Private networks** را انتخاب کن.

گزینه‌های اختیاری (به‌صورت پیش‌فرض خاموش، در همان تب): *نمایش و کنترل صفحه‌ی کامپیوتر از گوشی*، *دستورهای سیستمی (قفل / خواب / خاموشی)*.

## گزینه‌های خط فرمان و پوشه‌ی داده

```text
phone-bridge --version          # نمایش نسخه
phone-bridge --lang en|fa       # انتخاب زبان رابط (به خاطر سپرده می‌شود)
```

زبان را در خود برنامه هم می‌شود عوض کرد (دکمه‌ی **EN / فا** بالای پنجره؛ برنامه خودش دوباره اجرا می‌شود).

جای ذخیره‌ی چیزها:

| چه چیزی | کجا |
|---|---|
| تنظیمات (`phone_bridge_config.json`)، فونت‌ها، `platform-tools/` دانلودشده | کنار `phone_bridge.py` (قابل‌حمل). اگر با `pip` نصب شده باشد: `~/.phone-bridge`. اگر exe باشد: کنار exe. با متغیر محیطی `PHONE_BRIDGE_HOME` عوضش کن. |
| اسکرین‌شات‌ها | `Pictures/PhoneBridge` |
| ضبط‌های ویدیویی | `Videos/PhoneBridge` |
| عکس‌هایی که از گوشی آورده می‌شوند | `Pictures/PhoneBridge` |

برای بازنشانی همه‌چیز، برنامه را ببند و `phone_bridge_config.json` را پاک کن.
