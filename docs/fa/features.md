# فهرست امکانات

[← فهرست مستندات](../README.md) · [English](../en/features.md) · **فارسی**

همه‌ی کارهایی که Phone Bridge می‌کند، بر اساس جایی که پیدایشان می‌کنی. جزئیات هر مورد در **[راهنمای استفاده](usage.md)** است.

> *راهنمای وضعیت تأیید* — **R** = روی گوشی واقعی توسط کاربر تأیید شده · **S** = با تست خودکار روی `adb` شبیه‌سازی‌شده پوشش داده شده (رفتار روی گوشی‌های واقعی ممکن است با نسخه‌ی اندروید/سازنده فرق کند).

## اصلی

| امکان | کجا | تأیید |
|---|---|---|
| نمایش زنده‌ی گوشی (تشخیص جهت صفحه، تازه‌سازی ۰٫۲۵ تا ۱ ثانیه) | کنترل | R، S |
| موس ← لمس، لمس طولانی، swipe، اسکرول، برگشت (کلیک راست)، خانه (کلیک وسط) با افکت موج | کنترل | R، S |
| کیبورد کامپیوتر ← تایپ و کلیدهای ویژه روی گوشی | کنترل | R، S |
| کلیدهای ناوبری (برگشت، خانه، اخیر)، روشن/خاموش، صدا، اعلان‌ها | نوار ابزار کنترل | S |
| اتصال با USB، جفت‌سازی QR، کد جفت‌سازی، IP دستی، تبدیل USB به Wi-Fi | اتصال | R (QR)، S |
| پیدا کردن / دانلود / انتخاب دستی خودکار `adb` | اتصال | S |
| تم تیره و روشن، آیکون‌های برداری، فونت وزیرمتن | کل برنامه | R |
| رابط فارسی ⇄ English با آینه‌شدن کامل راست‌به‌چپ/چپ‌به‌راست | دکمه‌ی بالای پنجره | R، S |
| گوشی به‌عنوان کیبورد (سازگار با تصحیح خودکار و فارسی) و تاچ‌پد کامپیوتر | صفحه‌ی گوشی | S |

## ۵۰ امکان افزوده‌شده

### تب کنترل (۱۴)

| # | امکان | توضیح |

| ۳ | **چرخش صفحه** | قدم‌های ۹۰ درجه؛ چرخش خودکار را خاموش می‌کند |

## علاوه بر آن‌ها در صفحه‌ی گوشی

حرکت‌های تاچ‌پد چندلمسی (اسکرول دوانگشتی، کلیک راست با لمس دوانگشتی، لمس‌و‌کشیدن)، کلیدهای چسبنده‌ی Ctrl/Alt/Shift/Win، رابط دوزبانه با دکمه‌ی EN/فا، تیره/روشن بر اساس گوشی، بازخورد لرزشی، و فونتی که از خود کامپیوتر می‌آید (آفلاین هم کار می‌کند).
